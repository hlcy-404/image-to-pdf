# 图片转PDF工具

将大量习题截图自动转换为PDF文件，每页A4横向纸张并排放置3张图片。

## 功能特点

- ✅ 自动处理多个子目录，每个子目录生成一个对应的PDF文件
- ✅ A4横向页面布局（297mm x 210mm）
- ✅ 每页并排放置3张习题图片
- ✅ 自动图片缩放，保持宽高比
- ✅ 支持PNG、JPG格式
- ✅ 自然排序（正确处理文件名中的数字）
- ✅ 高质量输出（150 DPI）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

1. 确保您的图片文件放在 `image` 目录下的各个子目录中
2. 运行脚本：

```bash
python convert_images_to_pdf.py
```

3. 生成的PDF文件将保存在 `output` 目录中

## 技术参数

- **页面尺寸**: A4横向（842 x 595 points）
- **分辨率**: 150 DPI（1754 x 1241 像素）
- **每页图片数**: 3张
- **图片布局**: 水平并排，等宽分布
- **边距**: 自动计算（宽度1%，高度2%）
- **缩放方式**: 保持原始宽高比，使用高质量LANCZOS算法

## 处理流程

1. 扫描 `image` 目录下的所有子目录
2. 对每个子目录：
   - 读取所有PNG/JPG图片
   - 按文件名自然排序
   - 每3张图片创建一页A4横向页面
   - 自动缩放图片以适应页面
   - 合并所有页面生成PDF
3. 输出到 `output` 目录

## 注意事项

- 原始图片尺寸：1290 x 2796 像素
- 支持的图片格式：PNG、JPG、JPEG
- 确保有足够的磁盘空间（每个PDF约几十MB）
- 处理大量图片时可能需要几分钟时间

## 常见问题

**Q: 图片顺序不对怎么办？**  
A: 脚本使用自然排序，会正确处理文件名中的数字。确保文件名格式一致。

**Q: 可以修改每页图片数量吗？**  
A: 可以。编辑 `convert_images_to_pdf.py` 中的 `IMAGES_PER_PAGE` 常量。

**Q: 如何调整输出质量？**  
A: 修改 `DPI` 常量（当前150）和保存时的 `quality` 参数（当前95）。
